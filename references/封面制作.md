# All In 具身封面制作

已有项目封面 Skill 时，结合本期要求使用项目内的 `skills/all-in-cover/SKILL.md` 和 `封面设计规范.md`。没有项目规范时，使用本页和创作者提供的当期素材。

1. 从当期原片选自然、清楚、符合主题的本人表情或动作，记录帧时间。优先保留真实背景、衣服和手势。主题海报背景按当期选择使用。调整表情或视线时保留身份、眼镜、发型和摄影感，并遵守本期授权。
2. 采用小的 `All In 具身｜Day N` 标识、大的主题和较小的知识点说明。参考创作者认可的封面层级、表情和随主题变化的颜色及贴纸。箭头、问号、标签对应具体物体或知识点，避开眼睛、嘴和手指。
3. 用可用的图像编辑工具或 imagegen 基于当期素材制作十张独立 PNG 和总览。改变构图、字形、配色或语义图形，给出真实可选的版本。检查标题逐字、人物身份、缩略图可读性与裁切。
4. 用户先选一张主封面，助手再从剩余候选选三张小红书 PK。保存主封面和备选顺序。抖音和小红书通常用项目 3:4 版，视频号按当前入口适配。回看上传后的实际裁切，保持人像比例。
