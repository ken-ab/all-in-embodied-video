# 三平台手机预览

成片验收后，用包内 `scripts/mobile-preview/build_preview.py` 生成抖音、小红书、视频号的本地手机界面模拟。项目内已有更新版本时可用项目版本。需要 Python 3.11 或更新版本，并让当前环境能找到 `ffmpeg` 和 `ffprobe`。

从本 Skill 文件夹运行以下命令，把路径换成本期真实文件。

```sh
python3 -X utf8 scripts/mobile-preview/build_preview.py \
  --video "/路径/成片.mp4" \
  --cover "/路径/主封面.png" \
  --title "本期标题" \
  --out "/路径/本期/手机预览" \
  --start
```

Windows 使用当前可用的 Python 命令。可选 `--srt` 添加长字幕检查点，`--checkpoints` 指定带 `label` 和成片秒数 `time` 的 JSON 数组。脚本返回本机预览地址，并在输出目录生成预览清单和对应系统的启动文件。预览包在另一台电脑解压后，使用那台电脑上的脚本对最终 MP4 重新生成本地入口。

验证三平台可播放同一版 MP4，标题、文案和封面对应当前交付。回看首屏、长字幕、上半屏技术图和结尾。页面显示的是本地模拟。
