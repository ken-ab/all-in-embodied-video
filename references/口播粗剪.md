# 口播粗剪

这套流程从实录、笔记和现有字幕开始。仓库内脚本用 Python 3.11+、FFmpeg 和 FFprobe（FFmpeg 需支持 libx264）。已有剪映或其他剪辑器时，也可以在其中执行同一份剪辑清单。

## 1. 核对素材和真实表达

按本期笔记、录制关键词、原声和画面识别主讲、演示、补录、重复录制和收尾。先看开头、关键解释和结尾，再听有歧义的段落。对照同一句的多个录制版本，优先保留表达正确、完整、画面和人声可用的一次。整理 `口播稿.md`，给拟删的重讲、口误、录制指令和补录点写明原片时间及理由。

如已有自动转录或剪辑器的字幕，保留与原片对应的时间。没有自动转录时，按原声手工整理原片字幕，或先做成片再标成片字幕。用实际试听判断轻声、换气、笑声、停顿及前后因果。下面命令只找音量较低的候选区间。

```sh
python3 scripts/rough_cut.py inspect "主讲.mp4" "补录.mp4"
```

可用 `--noise-db` 和 `--min-quiet` 调整检测。低音量区间先回听，尤其是起音、尾音、背景声与重要停顿。口误影响技术结论时，标时间点并提供一句可录的替换稿，先完成其余可剪段落。

## 2. 确定唯一的保留清单

在 `keep.json` 的 `keep` 中，按成片顺序写每一段保留范围。开始和结束值是对应原片播放器从零开始的秒数，路径相对清单所在目录。可选 `srt` 使用该原片时间轴上的 UTF-8 字幕。

```json
{
  "sources": {
    "talk": {"video": "素材/主讲.mp4", "srt": "字幕/主讲.srt"},
    "demo": {"video": "素材/演示.mp4"}
  },
  "keep": [
    {"source": "talk", "start": 1.2, "end": 8.6},
    {"source": "demo", "start": 0.4, "end": 2.9},
    {"source": "talk", "start": 10.1, "end": 18.4}
  ]
}
```

保持原速。纯口播通常保留原顺序，补录放到它实际补充或替换的位置。跨镜头前后各听一遍，确认开口完整、上下句顺畅、切前和切后都没有吞字。定下的清单是字幕、图卡、章节与预览的共同时间线。清单变更后按新的剪点更新这些资产。

## 3. 渲染、配画面和验收

```sh
python3 scripts/rough_cut.py render --plan keep.json --output 粗剪.mp4
```

可用 `--width`、`--height`、`--fps` 指定画布和帧率，默认 1080×1920、30 fps。脚本统一画幅和音轨，保留原比例，将选中的区间拼成 H.264/AAC MP4，检查成片长度并解码验证。素材含有效源 SRT 片段时，同时输出重排后的同名 SRT。预览首尾、逐个试听切点并确认音画同步，复核靠近切点的字幕和技术术语。

随后从学习笔记挑实图、示意和链路。把图片或解释字对齐到实际讲到的位置，在剪辑器或现有合成工具里完成上半屏、字幕样式和声音处理。用剪辑器导出最终 MP4，保留字幕、图卡和工程或可编辑素材。再检查音画同步、长字幕、首屏及收尾，生成三平台预览和发布包。[手机预览工具](手机预览.md)
