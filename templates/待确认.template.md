# 待确认

复盘和返修中需要创作者回答的事都排在这里，下期开工时逐条处理。创作者回「要」就照「要了之后」那一列执行；回「不要」就删掉这条；没回复的留到下次。处理规则见 [反馈与学习](../references/反馈与学习.md) 第 7 节。

每条一个小节，按产生的时间先后排：

## YYYY-MM-DD｜Day N｜类型

```text
类型       写法 pattern 候选 / 评分规则升级提议 / 热门评论待补 / 制作规则候选 / 对标待导入
来源       predictions/xxx.md 复盘段，或 Day N 返修记录.md 单元 X
内容       （原文照抄，不改写）
证据       （数据、单元原文、出现的期数）
要了之后   （例：按 script_patterns 模板追加，标「待验证」；说「升级 rubric」；写进制作规则「已确认」段）
```
